Quick answers

The report is empty right after install. The first import is still running. It rebuilds the last 10 sprints of each Scrum board in the background. The status line at the top of the report shows progress.

addedAfterSprintStart("My sprint") says the sprint is unknown. Use the sprint ID, for example addedAfterSprintStart(42), or wait until the import finishes. The ID is shown in the report and in the sprint's URL.

The function says there are more than 1,000 issues. Jira limits app JQL functions to 1,000 values. Use the report for that sprint instead.

Some changes are hidden. The report only shows issues you're allowed to see in Jira.

Re-run the import. Jira administrators can click Re-run import on the report page.
